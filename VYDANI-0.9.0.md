# Evertally 0.9.0 — talentové profily, statistiky instancí a Sleeping Bag

13. listopadu 2026.

- Přenositelné talentové profily ETB1, bezpečný import s kontrolou třídy/schématu/podmínek a vlastní názvy. Výchozí zoom 75 %, nastavitelný 50–150 %.
- 13 zdrojovaných Forever plánů pro devět tříd, z toho pět pro druida. Kompatibilita se kontroluje vůči stromu klienta; skutečné body se nikdy netrénují.
- Dungeon/raid, instance, třída a rasa; detail hráče a běhu, bossové/splity/sestava; DPS/HPS z připsaných a pozorovaných bojových intervalů. Nový sběr přes native damage meter a legacy log. Chybějící/částečné údaje zůstávají mimo pořadí.
- Oba návody Cozy Sleeping Bag jsou celé v addonu, s questy a navigací k devíti zastávkám, oddělené začátky pro Alianci a Hordu.
- Webový kontrakt, detail a žebříček přijmou nová volitelná měření. Veřejný profil nevystavuje jména ostatních jen kvůli souhlasu jednoho účastníka; export bez identity anonymizuje i vlastní combat actor.

Zdroje: https://wowhandbook.com/classes/druid/talents/#build-druid-feral-leveling ; https://www.icy-veins.com/wow-forever/sleeping-bag/ ; https://wowhandbook.com/news/cozy-sleeping-bag-in-wow-forever/ ; Blizzard Forever API DamageMeterDocumentation.lua.

Náhledy obou rozměrů a dialogů jsou odděleným modelem rozložení, nikoli herním snímkem. Ve hře po instalaci zatím nepotvrzeno. Starší historie bez měření není zpětně dopočítaná; neexistuje tvrzení o kompletním Raider.IO skóre či celoserverovém soutěžním žebříčku.

Po instalaci WoW úplně ukončit a znovu spustit. Mapové plánování 0.8.4 zůstává součástí stejného addonu.
