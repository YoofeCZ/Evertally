# Evertally 0.11.3 (addon)

Aplikace zůstává **0.9.19**, nová není potřeba.

## Zbytek stránek ve stylu menu průvodce

- **Recepty:** vpravo panel jako v Databázi: ikona profese, profese, barvy dovednosti, co recept vyrobí a suroviny jako klikací řádky.
- **Vnitřek dungeonu:** plochý detail s tenkým posuvníkem, tlačítko zpět a „Ukázat vchod / Navigovat“ jsou tlačítka průvodce.
- **Mapa a cesty:** Mapa, Cesta, Sbírání, Služby a Instance jsou záložky nahoře. Sbírání, Služby a Instance mají vyhledávání a panel vpravo jako Databáze.
- **Lidé a Talenty:** tlačítka a pole na psaní mají vzhled průvodce.
- Všechny detaily bez pergamenu a fialového přechodu nahoře.

## Menu

- **Lišta sekcí je dole:** Evertally, Guides, Database a Rares vlevo, Import a Nastavení vpravo. Znak Evertally je u nápisu v pravém panelu a stránka je širší.
